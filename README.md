# UnitSync

Ferramenta para automatizar a associação de **unidades de medida em lote** durante a importação de notas fiscais (XML) no **Hiper ERP**.

## 🎯 Objetivo

O **UnitSync** elimina o mapeamento manual recorrente ao importar notas fiscais de diferentes fornecedores.

A ferramenta permite definir **regras de conversão em lote**, garantindo:

* ⚡ Maior agilidade no processo de importação;
* 📦 Padronização das unidades de medida no estoque;
* ✅ Redução de erros operacionais;
* 🔄 Automatização de tarefas repetitivas no Hiper ERP.

## 📋 Pré-requisitos

Antes de utilizar o UnitSync, certifique-se de possuir:

* Acesso ao sistema **Hiper ERP**;
* Permissões adequadas para execução de scripts/extensões no navegador;
* **Google Chrome** ou **Microsoft Edge**.

## 🚀 Instalação

### Via Git — Desenvolvimento

Clone o repositório:

```bash
git clone https://github.com/Luanhotlinebr/unitsync-hiper.git
cd unitsync-hiper
```

### Instalação no Navegador — Chrome / Edge

1. Acesse:

   * Chrome: `chrome://extensions`
   * Edge: `edge://extensions`

2. Ative o **Modo do desenvolvedor** no canto superior direito.

3. Clique em **Carregar sem compactação** (*Load unpacked*).

4. Selecione a pasta raiz do projeto:

```text
C:\Users\Luan Sousa\Documents.1-programacao\unitsync
```

5. A extensão será carregada e estará disponível no navegador.
